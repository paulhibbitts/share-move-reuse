# Docsify-This

A free, open-source web app that turns online Markdown files into styled, responsive web pages – no signup, no install.

- **Instant pages:** paste the address of any public Markdown file, such as one on GitHub, and it's a web page in seconds
- **One page or a whole site:** several files become a site with a sidebar, Previous/Next, the ← → keys and search
- **Point-and-click styling:** the Web Page Builder sets fonts, colours and layout, saved in the page's address
- **Embeds almost anywhere:** Canvas, Moodle, Brightspace, WordPress and more
- **Rich content:** H5P activities, LaTeX math and Mermaid diagrams
- **Edit in place:** change the Markdown file, and the page updates shortly after

Named a finalist in the Open Infrastructure category of the 2024 Open Education Awards for Excellence.

**Start from a template:** a [Guide Site](https://github.com/hibbitts-design/docsify-this-guide-site?target=_blank) for an open guide (a [Multiple Guides Site](https://github.com/hibbitts-design/docsify-this-multiple-guides-site?target=_blank) for several), or a [Course Site](https://github.com/hibbitts-design/docsify-this-multiple-page-course-site?target=_blank) for a course (a [Courses Site](https://github.com/hibbitts-design/docsify-this-courses-site?target=_blank) for several) – copy it to your GitHub account and edit the Markdown. When you want your own address and styling, the same files move to a Docsify Starter Kit (Part 3).

**Whole textbooks, too:** what started as a test of how portable Markdown is turned out to work for complete books. Four open textbooks converted from Pressbooks now run on Docsify-This, with no web server and no build step:

- **Chapters in the sidebar,** grouped by part, with Previous/Next on phones
- **Glossary terms** linked to their definitions
- **H5P activities** embedded or linked, as in the original book
- **Every page as Markdown,** ready to reuse or move to Grav (Part 4)
