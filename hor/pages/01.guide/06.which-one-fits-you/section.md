All the starters and converters in this guide are **free and open-source**:

- **"I want to share a textbook or guide"** → Open Publishing Space: demo with [one guide](https://demo.hibbittsdesign.org/grav-open-publishing-quark2/) or [several guides](https://demo.hibbittsdesign.org/variants/grav-open-publishing-quark2-guides/) · [download](https://getgrav.org/downloads/skeletons#open-publishing-space-site)
- **"I want a web home for my course – or several"** → Open Course Space: [demo](https://demo.hibbittsdesign.org/grav-open-course-space/) · [download](https://getgrav.org/downloads/skeletons#open-course-space-site) (an early preview)
- **"I already have a Pressbooks book or LMS course"** → the [Pressbooks](https://grav-pressbooks-converter.hibbittsdesign.org/) or [Common Cartridge](https://grav-common-cartridge-converter.hibbittsdesign.org/) Converter
- **"No web server? Start with Docsify"** → [Docsify-This](https://docsify-this.net/) or a [Docsify Starter Kit](https://hibbittsdesign.org/docsify-starter-kits.html), then the [Grav Docsify Bridge](https://grav-docsify-bridge.hibbittsdesign.org/) when you're ready for a full site – see the [Docsify](/docsify) guide

**Explore it in 5 minutes:**

1. **Add** `.md` to this page's address to see its Markdown
2. **Press** ← and → to move through this guide, like slides
3. **Add** `?embedded=true` to this page's address to see it as it would appear in your LMS
4. **Sign in** to [the read-only Admin 2 demo of this site's Open Publishing Space version](https://try.hibbittsdesign.org/read-move-reuse/admin?target=_blank) and open a page – such as this one – to see its Markdown

Then set up your own site:

1. **Download** a [term name="Starter skeleton"]starter skeleton[/term]: [Open Publishing Space](https://getgrav.org/downloads/skeletons?target=_blank#open-publishing-space-site) or [Open Course Space](https://getgrav.org/downloads/skeletons?target=_blank#open-course-space-site) (an early preview), both from getgrav.org
2. **Upload** it to your web host and unzip it (your host's file manager can do this), then open the site
3. **Open** Admin 2 by adding `/admin` to the site's address, set up your account, then follow **Getting Started** in its sidebar – each starter has a sample guide or course to start your own from

**Where to host:** many institutions offer web space for staff and students (often called a Domain of One's Own), and most low-cost web hosts run PHP 8.3 or newer.

**See it moved:** this same guide also runs, with the same content, as an Open Publishing Space guide on the [Quark 2](https://share-move-reuse.hibbittsdesign.org/guide?target=_blank) and [classic Quark](https://demo.hibbittsdesign.org/share-move-reuse/share-move-reuse-ops-quark/guide?target=_blank) themes, as an [Open Course Space course](https://demo.hibbittsdesign.org/share-move-reuse/share-move-reuse-ocs/guide?target=_blank), and on Grav Premium Helios as a [course hub](https://demo.hibbittsdesign.org/share-move-reuse/share-move-reuse-hch/guide?target=_blank) – and as plain Markdown pages on [Docsify-This](https://docsify-this.net/?basePath=https://raw.githubusercontent.com/paulhibbitts/docsify-this-share-move-reuse-site/main&homepage=home.md&name=Share%2C%20Move%2C%20Reuse&sidebar=true&loadSidebar=_sidebar.md&loadNavbar=_navbar.md&pagination=true&sticky-pagination=true&searchbox=true&dark-mode=auto&loadFavicon=favicon.png&zoom-images=true&keep-my-place=true&edit-link=https://raw.githubusercontent.com/paulhibbitts/docsify-this-share-move-reuse-site/main/home.md&edit-link-text=This%20page%20as%20Markdown&edit-link-emoji=:page_facing_up:&target=_blank).

> [!IMPORTANT]
> **Good to know:** publishing as a website keeps things simple, but there's no one-click ebook (EPUB or formatted PDF – pages print cleanly from the browser), you'll need a [term]PHP[/term] web host (no database)[^1], colleagues new to Markdown may need a little help to start, and [Grav](https://getgrav.org/?target=_blank) extras like definition and objectives boxes are [term name="Shortcode"]shortcodes[/term] that other tools would need converted. If you ever lose access to a web host, the free [Grav Docsify Bridge](https://grav-docsify-bridge.hibbittsdesign.org/?target=_blank) turns your guides or courses into a Docsify-This site, with no web server needed.
