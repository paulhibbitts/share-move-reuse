All the starters and converters in this guide are **free and open-source**, and you can explore the demos, try Admin 2 and try the converters with nothing to install:

- **"I want to share a textbook or guide"** → Open Publishing Space – edit it in the browser with Admin 2, and share it as a website with reading progress and even a blog or other custom pages: demo with [one guide](https://demo.hibbittsdesign.org/grav-open-publishing-quark2/?target=_blank) or [several guides](https://demo.hibbittsdesign.org/variants/grav-open-publishing-quark2-guides/?target=_blank) · [download](https://getgrav.org/downloads/skeletons?target=_blank#open-publishing-space-site)
- **"I want a web home for my course – or several"** → Open Course Space: [demo](https://demo.hibbittsdesign.org/grav-open-course-space/?target=_blank) · [download](https://getgrav.org/downloads/skeletons?target=_blank#open-course-space-site) (a preview release)
- **"I want to start using Markdown, with no web server"** → [Docsify-This](https://docsify-this.net/?target=_blank), starting from its [Guide Site](https://github.com/hibbitts-design/docsify-this-guide-site?target=_blank) or [Course Site](https://github.com/hibbitts-design/docsify-this-multiple-page-course-site?target=_blank) template, then the [Grav Docsify Bridge](https://grav-docsify-bridge.hibbittsdesign.org/?target=_blank) when you're ready for a full site – see the [Docsify](/docsify) guide
- **"I want to move or adapt a Pressbooks book, or move my LMS course"** → the [Pressbooks](https://grav-pressbooks-converter.hibbittsdesign.org/?target=_blank) or [Common Cartridge](https://grav-common-cartridge-converter.hibbittsdesign.org/?target=_blank) Converter

Then set up your own site:

1. **Download** a starter skeleton from [getgrav.org](https://getgrav.org/downloads/skeletons?target=_blank)
2. **Upload** it to your web host and unzip it (your host's file manager can do this), then open the site
3. **Open** Admin 2 by adding `/admin` to the site's address, set up your account and start writing

**Where to host:** many institutions offer web space for staff and students (often called a Domain of One's Own), and most low-cost web hosts run PHP 8.3 or newer.

> [!IMPORTANT]
> **Good to know:**
>
> - You'll need a PHP web host (no database), and you – or your host – look after updates and backups: Grav, its plugins and themes update from Admin 2's dashboard, and a backup is a copy of the site's folder
> - If you ever lose access to a web host, the free [Grav Docsify Bridge](https://grav-docsify-bridge.hibbittsdesign.org/?target=_blank) turns your guides or courses into a Docsify-This site, with no web server needed
> - Editing is in Markdown – quick to learn, but not a word processor, so some colleagues may need a little help to start (the premium Editor Pro plugin shows formatted text instead)
> - An open course site works alongside your LMS rather than replacing it – there are no grades, quizzes or enrolment
> - Some Grav 1.7 plugins and themes aren't updated for Grav 2 yet
> - There's no one-click import from WordPress – existing pages need converting to Markdown ([the usual route](https://getgrav.org/blog/grav-vs-wordpress?target=_blank))
> - There's no one-click ebook (EPUB or formatted PDF) – pages print cleanly from the browser
> - Grav extras like definition and objectives boxes are shortcodes that other tools would need converted
